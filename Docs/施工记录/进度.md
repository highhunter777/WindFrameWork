| 开发工具平台 | `Editor/Tooling` | 编辑态工具基建：校验运行器、工具中心窗口、模块脚手架、批处理入口；CI 阻断 + 编辑器手动，设计已定 | 📋 规划中 |

| 工具集 | `Kits` | 通用工具与编辑器扩展，持续沉淀 | 📋 规划中 |
